# Guessing Game 🎯

## Overview  
The **Guessing Game** is a fun and interactive console-based game where players try to guess a randomly generated number between 1 and 100. The game includes multiple difficulty levels, hints, and a high score tracking system.

---

## How to Play  
1. **Choose Your Difficulty:**  
   - **Easy:** 15 attempts  
   - **Medium:** 10 attempts  
   - **Hard:** 5 attempts  

2. **Make Your Guess:**  
   - Enter a number between 1 and 100.  
   - If your guess is incorrect, the game provides feedback (higher/lower).  
   - You can request hints by entering `-1`. Hints are only available after 3 attempts.  

3. **Win the Game:**  
   - Guess the correct number within the allowed attempts to win.  
   - If successful, your score is compared to the current high score for the chosen difficulty level.

4. **Track Your Progress:**  
   - The game tracks and displays high scores for each difficulty level.

---

## Features  
- 🎮 **Three Difficulty Levels:** Adjust the challenge with easy, medium, or hard mode.  
- 💡 **Hints:** Get tips on parity (odd/even) and range after 3 failed attempts.  
- 🏆 **High Scores:** Save your best performance for each difficulty level.  
- ⏱️ **Timer:** See how long it takes to guess correctly.  
- 😊 **Fun and Engaging Messages:** Enjoy playful emojis and feedback throughout the game.
